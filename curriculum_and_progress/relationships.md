# Canonical topic and session relationships

This reviewed registry is the canonical Level-2 normalization of cross-topic semantics. The source and target orientation is `source -> target`: knowledge or evidence from the source informs the target. Topic plans define each topic's content; this registry defines how those topics relate.

Only `hard_prerequisite` relationships block. A `topic_entry` edge blocks topic entry. A hard edge with stable target-session IDs blocks only those sessions. `recommended_background` is scheduled just in time, `related` records a non-blocking interface, and `feedback` returns evidence without creating a prerequisite cycle.

Every row was inspected semantically during the 27 August 2026 exhaustive curriculum audit. Cross-topic names in a session's canonical `Prerequisites` field are represented as hard gates for that session. `manual_review` confidence identifies conservative topic-level judgments that remain explicit rather than being hidden as generic prerequisites.
