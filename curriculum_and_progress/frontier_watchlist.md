## Audit decision

P158–P162 were removed from this watchlist because they are already integrated as primary papers in E3's Frontier Continuation. ## Promotion rule

Promote an item only when it materially changes a durable lineage and has sufficiently clear methodology, data provenance, baselines, evaluation protocol, failure analysis, compute requirements, and preferably code or independent reproduction.
